# Excel填表规范说明（多页签配置模式）

## 一、文件命名规范

### 格式
```
ClassName[中文名].xlsx
```

### 示例
- `Item[道具].xlsx` - 道具配置表
- `Skill[技能].xlsx` - 技能配置表
- `Player[玩家].xlsx` - 玩家配置表

## 二、页签结构

每个Excel文件包含多个页签：

### 1. main 页签（表定义页签）

**第一个页签必须是 `main`**，用于定义其他数据页签的结构。

#### main页签结构：

| 导出开关 | file（页签名） | name（中文名） | client（客户端导出） | server（服务端导出） | type（表格类型） | END |
|----------|----------------|----------------|----------------------|----------------------|------------------|-----|
| TRUE     | skillData      | 技能数据       | YES                  | YES                  | 主键表           |     |
| TRUE     | buffData       | BUFF数据       | YES                  | NO                   | 主键表           |     |
| FALSE    | testData       | 测试数据       | NO                   | NO                   | 参数表           |     |
| END      |                |                |                      |                      |                  |     |

#### 字段说明：

| 字段 | 说明 | 可选值 |
|------|------|--------|
| **导出开关** | 控制该页签是否导出 | TRUE/FALSE |
| **file** | 页签名称（英文） | 对应数据页签的名称 |
| **name** | 页签中文注释 | 用于代码注释 |
| **client** | 是否导出到客户端 | YES/NO |
| **server** | 是否导出到服务端 | YES/NO |
| **type** | 表格类型 | 参数表/枚举表/主键表/数组表/分组表 |

#### 表格类型说明：

| 类型 | 说明 | 用途 |
|------|------|------|
| **参数表** | 单条配置，通常只有一行数据 | 全局参数、常量配置 |
| **枚举表** | 枚举定义 | 枚举值配置 |
| **主键表** | 以ID为主键的配置表 | 最常见的配置表类型 |
| **数组表** | 数组结构配置 | 列表型配置 |
| **分组表** | 按组分类的配置 | 分组管理配置 |

### 2. 数据页签

根据main页签的定义，创建对应的数据页签。

#### 数据页签结构（标准4行表头）：

| 字段注释 | 技能ID | 技能名称 | 技能类型 | 伤害值 | 冷却时间 | END |
|----------|--------|----------|----------|--------|----------|-----|
| 字段名   | Id     | Name     | Type     | Damage | Cooldown |     |
| 数据类型 | int    | string   | enum_SkillType | int | float |     |
| 数据行1  | 1001   | 火球术   | Magic    | 100    | 2.5      |     |
| 数据行2  | 1002   | 冰冻术   | Magic    | 80     | 3.0      |     |
| END      |        |          |          |        |          |     |

#### 表头结构：

| 行号 | 内容 | 说明 |
|------|------|------|
| 第1行 | 字段中文注释 | 生成代码注释、TS注释 |
| 第2行 | 英文字段名 | 变量名，必须符合编程语言命名规范 |
| 第3行 | 字段数据类型 | 支持基础类型、枚举、数组、自定义类型 |
| 第4行+ | 数据行 | 实际配置数据 |

## 三、数据类型支持

### 基础类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | 100 |
| `long` | 长整数 | 1000000 |
| `float` | 单精度浮点数 | 3.14 |
| `double` | 双精度浮点数 | 3.14159 |
| `bool` | 布尔值 | true/false/1/0/yes/no |
| `string` | 字符串 | Hello World |

### 数组类型

格式：`类型[]`

- `int[]` - 整数数组，如：`1,2,3,4,5`
- `string[]` - 字符串数组，如：`a,b,c`
- `enum_xxx[]` - 枚举数组

### 枚举类型

格式：`enum_枚举名`

- `enum_ItemType` - 物品类型枚举
- `enum_ItemType[]` - 物品类型枚举数组

### 自定义对象类型

格式：首字母大写的类型名

- `Vector3` - 三维向量
- `RewardInfo` - 奖励信息

自定义对象数据格式：`key1=value1;key2=value2`

## 四、完整示例

### 示例：Item[道具].xlsx

#### main 页签：

| 导出开关 | file | name | client | server | type | END |
|----------|------|------|--------|--------|------|-----|
| 导出     | 页签 | 名称 | 客户端 | 服务端 | 类型 |     |
| TRUE     | itemData | 道具数据 | YES | YES | 主键表 | |
| TRUE     | itemType | 道具类型 | YES | NO | 枚举表 | |
| END      |      |      |        |        |      |     |

#### itemData 页签：

| 道具ID | 道具名称 | 道具类型 | 售价 | 堆叠数量 | END |
|--------|----------|----------|------|----------|-----|
| Id     | Name     | Type     | Price| StackCount | |
| int    | string   | enum_ItemType | int | int | |
| 1001   | 铁剑     | Weapon   | 100  | 1        |     |
| 1002   | 木盾     | Armor    | 50   | 1        |     |
| 1003   | 红药水   | Consumable | 10 | 99       |     |
| END    |          |          |      |          |     |

#### itemType 页签：

| 类型ID | 类型名称 | END |
|--------|----------|-----|
| Id     | Name     |     |
| int    | string   |     |
| 1      | Weapon   |     |

| END    |          |     |

## 五、特殊标记

- **END行标记**：数据行结束后，在下一行填写 `END`，表示数据结束
- **END列标记**：字段列结束后，在下一列填写 `END`，表示字段结束
- **导出开关**：main页签第一列控制页签是否导出

## 六、注意事项

1. **main页签必须是第一个页签**，用于定义其他页签的结构
2. **file列必须对应实际存在的页签名称**
3. **数据页签不需要导出开关列**，导出控制在main页签统一管理
4. **字段名规范**：使用英文驼峰命名，如 `ItemId`、`PlayerName`
5. **类型声明**：数据页签第三行必须正确声明类型
6. **主键约定**：字段名为 `Id` 或 `ID` 的字段会被视为主键
7. **临时文件**：以 `~$` 开头的Excel临时文件会被自动忽略

## 七、导出规则

根据main页签的配置，工具会：

1. 只导出导出开关为 `TRUE` 的页签
2. 根据 `client` 列决定是否生成C#/TypeScript代码
3. 根据 `server` 列决定是否生成服务端配置（预留）
4. 每个页签生成独立的JSON文件和代码文件

```
└── TypeScript/

    ├── ItemData.ts
    ├── ItemType.ts

```
