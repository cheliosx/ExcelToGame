# Excel填表规范说明

## 一、表格结构规范

### 1. 表头结构（固定4行）

| 行号 | 内容 | 说明 |
|------|------|------|
| 第1行 | 字段中文注释 | 生成代码注释、TS注释 |
| 第2行 | 英文字段名 | 变量名，必须符合编程语言命名规范 |
| 第3行 | 字段数据类型 | 支持基础类型、枚举、数组、自定义类型 |
| 第4行+ | 数据行 | 实际配置数据 |

### 2. 特殊标记

- **END行标记**：数据行结束后，在下一行第一列填写 `END`，表示数据结束
- **END列标记**：字段列结束后，在下一列填写 `END`，表示字段结束
- **导出开关列**：第一列固定为导出开关，值为 `true` 的行才会被导出

## 二、数据类型支持

### 基础类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | 100 |
| `long` | 长整数 | 1000000 |
| `float` | 单精度浮点数 | 3.14 |
| `double` | 双精度浮点数 | 3.14159 |
| `bool` | 布尔值 | true/false/1/0/yes/no |
| `string` | 字符串 | Hello World |

### 数组类型

格式：`类型[]`

- `int[]` - 整数数组，如：`1,2,3,4,5`
- `string[]` - 字符串数组，如：`a,b,c`
- `enum_xxx[]` - 枚举数组

### 枚举类型

格式：`enum_枚举名`

- `enum_ItemType` - 物品类型枚举
- `enum_ItemType[]` - 物品类型枚举数组

### 自定义对象类型

格式：首字母大写的类型名

- `Vector3` - 三维向量
- `RewardInfo` - 奖励信息

自定义对象数据格式：`key1=value1;key2=value2`

## 三、继承关系

表格文件名支持继承语法：`子表名:父表名.xlsx`

例如：`Equipment:Item.xlsx` 表示 Equipment 继承自 Item

## 五、注意事项

1. **导出开关**：只有第一列为 `true` 的行才会被导出
2. **END标记**：数据行末尾必须填写END标记，否则会继续读取空行
3. **字段名规范**：使用英文驼峰命名，如 `ItemId`、`PlayerName`
4. **类型声明**：第三行必须正确声明类型，否则会导致解析错误
5. **主键约定**：字段名为 `Id` 或 `ID` 的字段会被视为主键
6. **临时文件**：以 `~$` 开头的Excel临时文件会被自动忽略
